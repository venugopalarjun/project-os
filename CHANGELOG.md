# Changelog

**Last updated:** 2026-11-03

## Version 2 — 2026-11-03
- **Twelve rules, up from seven.** Added: new asks go through FEEDBACK first; the owner sets priorities; wireframe first for anything visual; a fixed bug leaves a test behind; checks run before anything ships.
- **ROADMAP.md is now a flat feature index** (one row per feature, flip a status cell) instead of a staged checklist. Stages survive as a column.
- **FEEDBACK.md uses numbered asks** (`A-01`, `A-02`…) so asks, decisions and roadmap rows can point at each other.
- **New templates:** `DESIGN.md` (design system), `CHECKS.md` (what must be true before shipping), `PROJECT-INSTRUCTIONS.md` (paste into your AI tool), `wiki/wireframes.md` (how to do wireframes).
- **New guides:** `GETTING-STARTED.md` (step by step, for non-coders) and `reference/workflow.md` (idea → release).
- `SKILL.md` gains modes for running a request end to end and for setting up checks.

## Version 1 — 2026-10-06
- First public version: nine files, `wiki/`, backup script, seven rules.
